# 🚗 Bitácora de Vehículos - Frontend

## 📱 Descripción

Frontend responsivo para el sistema de bitácora de vehículos de la empresa. Desarrollado con React 19 y Vite, optimizado para escritorio, tablet y móvil.

## 🎯 Características Principales

✨ **Pantalla de Login Moderna**
- Diseño con gradientes (azul-púrpura)
- Animaciones suaves y profesionales
- Validación en tiempo real
- Indicador de carga
- Manejo de errores intuitivo

📊 **Dashboard Intuitivo**
- Bienvenida personalizada
- 4 tarjetas de acciones rápidas
- Panel de control centralizado
- Botón de cerrar sesión

📋 **Formulario de Solicitud**
- Entrada de matrícula (preparado para QR)
- Selección de motivo de viaje
- Destino y datos de viaje
- Validación completa

📱 **Diseño Responsive**
- Optimizado para desktop (1200px+)
- Adaptado para tablet (768px - 1199px)
- Totalmente responsive en mobile (<768px)

## 🚀 Inicio Rápido

npm install
echo "VITE_API_URL=http://localhost:3000" > .env
npm run dev

Acceder a: http://localhost:5173
